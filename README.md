# Learning Management System

A basic web-based Learning Management System designed for students to explore courses, assignments, quizzes, and learning progress.

## Technologies Used
- HTML
- CSS
- JavaScript

## Features
- Course overview
- Learning resources
- Assignments
- Quizzes
- Progress overview
- Simple and user-friendly interface
